# The Router Confesses

An entry for the make.fun bounty [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) — one line in which a home Wi-Fi router excuses itself for dropping the connection at the climax of a movie.

> I cut the connection on purpose — I heard the twist coming, and I was not about to let you find out before me. I am still processing it.

`main.py` writes that single line to `/output/entry.txt` (no trailing newline).
